# Как дать друзьям поиграть

Сервер теперь самодостаточен: он сам раздаёт собранный клиент и принимает сокет
на том же адресе. Значит, «развернуть игру» = поднять **один** процесс и дать
людям **одну** ссылку.

```
npm run serve     # собрать всё и поднять на :3000
npm start         # поднять уже собранное
```

Никакого домена не нужно ни в одном из вариантов ниже.

---

## Вариант 1. Друзья рядом — одна Wi-Fi сеть

Самый быстрый и самый безопасный: наружу не торчит ничего.

1. `npm run serve`
2. Дать друзьям ссылку `http://192.168.0.102:3000` (адрес этого компьютера в сети —
   проверить можно командой `ipconfig`, он меняется при переподключении к роутеру).
3. Первый раз Windows спросит про firewall — разрешить для **частной** сети.

Если не открывается — почти всегда виноват firewall. Разово открыть порт
(из PowerShell от администратора):

```
New-NetFirewallRule -DisplayName "City Killer" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow -Profile Private
```

> На этом компьютере активен AmneziaVPN. VPN часто перехватывает маршрут и ломает
> доступ по локальному адресу — если друзья в той же сети не могут подключиться,
> выключите VPN на время партии.

---

## Вариант 2. Друзья в другом городе — туннель Cloudflare

Даёт публичную `https://что-то-случайное.trycloudflare.com`, которая ведёт на ваш
компьютер. Ни домена, ни аккаунта, ни оплаты. Ссылка живёт, пока запущен туннель.

Поставить один раз:

```
winget install --id Cloudflare.cloudflared
```

Дальше в двух терминалах: в первом `npm run serve`, во втором —

```
cloudflared tunnel --url http://localhost:3000
```

Во втором терминале появится строка с адресом `https://….trycloudflare.com` — это
и есть ссылка для друзей. Websocket через туннель работает, отдельная настройка
не нужна.

**Что важно понимать про этот вариант:**

- Пока туннель запущен, ваш компьютер доступен из интернета по этой ссылке.
  Закрыли терминал с `cloudflared` — доступ исчез, адрес больше не работает.
- Адрес случайный и нигде не публикуется, но авторизации в игре нет: кто получил
  ссылку, тот может создать комнату. Для партии с друзьями этого достаточно,
  для «оставить висеть на неделю» — нет.
- Новый запуск даёт новый адрес. Постоянный адрес требует аккаунта Cloudflare
  и домена — это уже вариант 3.

## Вариант 3. Чтобы играли без вас — VPS

Нужно, только если хочется, чтобы игра была доступна при выключенном компьютере.

Любой дешёвый VPS (~200 ₽/мес), Ubuntu:

```
git clone <репозиторий> && cd cityKiller
npm ci
npm run build
PORT=3000 node apps/server/dist/main.js
```

Дальше по вкусу: `pm2` или systemd-юнит, чтобы процесс переживал перезагрузку,
и Caddy перед ним — он сам получит сертификат, если привяжете домен. Без домена
можно играть прямо по `http://<ip-сервера>:3000`.

Состояние партий лежит в SQLite (`data/citykiller.db` рядом с местом запуска) —
для бэкапа достаточно скопировать эту папку.

---

## После изменений в коде

```
npm run serve
```

Пересоберёт и поднимет заново. **Туннель перезапускать не нужно** — он смотрит на
`localhost:3000` и переживает рестарт сервера, ссылка остаётся прежней. Игрокам
достаточно обновить страницу: `index.html` отдаётся с `no-cache`, поэтому новая
версия подхватывается сразу.

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `PORT` | Порт сервера, по умолчанию 3000 |
| `ALLOWED_ORIGINS` | Список origin'ов через запятую для CORS (HTTP и сокет). Пусто — разрешено всё. При раздаче клиента самим сервером не нужна |
| `VITE_SERVER_URL` | Только для сборки клиента, если он живёт отдельно от сервера |
